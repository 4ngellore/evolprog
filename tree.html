Мова C

Еталон низькорівневої ефективності та портативності. Сформувала синтаксис більшості сучасних мов.

#include <stdio.h>
int main() {
    printf("Hello, World!\n");
    return 0;
}
1985 · Б'ярн Страуструп Системна / ООП

C++

Розширив C об'єктно-орієнтованими класами та шаблонами. Основа ігрових рушіїв і високопродуктивних систем.

#include <iostream>
int main() {
    std::cout << "C++ Speed\n";
}
2000 · Андерс Гейлсберг ООП / .NET

C#

Елегантна суворо типізована мова для вебсервісів, корпоративних систем, десктопу та ігор на Unity.

using System;
Console.WriteLine("Modern C#");

Максимальна читабельність синтаксису та головний стандарт у машинному навчанні, аналізі даних і автоматизації.
